Configurações
Ajuste as configurações do painel
🔑 GitHub Personal Access Token (PAT)

Necessário para publicar posts e disparar automações. O token deve ter permissão de repo ou contents:write e workflows:write.

🔎 Indexação Automática + Content Studio

Este secret autoriza o painel a usar o Worker calculaprazo-views-api para: (1) atualizar o sitemap.xml e notificar o Google automaticamente ao publicar, e (2) gerar conteúdo no IA Content Studio. Configure o mesmo valor da variável ADMIN_SECRET no Worker. Bing/Yandex são notificados separadamente pelo Crawler Hints nativo do Cloudflare (Painel do domínio → Cache → Crawler Hints) — ative lá uma única vez, não depende deste secret.

🤖 Provedores de IA (Content Studio)

Cole a chave de cada provedor que for usar (nenhuma é obrigatória). As chaves ficam só no seu navegador e são enviadas ao Worker apenas no momento da geração. O nome do modelo já vem preenchido com uma opção atual e barata/gratuita — troque se quiser usar outro.

📧 Newsletter (Supabase)

Necessário só pra aba Newsletter funcionar. A URL é a do seu projeto Supabase (ex.: https://abcdefgh.supabase.co). O secret é o mesmo valor que você configurou com supabase secrets set ADMIN_SECRET=... — fica só no seu navegador, nunca é commitado no repositório.
